# assets/

Hand-authored art that is NOT generated by the compositor.

## addison-logo.png

The title-screen logo, 1210x979, indexed-colour PNG with transparency.

It is loaded by `index.html` (`#title-logo`) and rendered with
`image-rendering: pixelated`, so it will scale to the title screen without
blurring at integer or non-integer sizes. Transparent background is expected —
the title screen supplies its own radial backdrop behind it.

If the file is absent the title screen falls back to a type-set treatment
automatically, so a missing logo never blocks the build or the game.

It is close to square, so the title screen caps it on HEIGHT (54vh) rather than
width — a width-only cap pushes the START GAME button off short screens.

## Note on the palette

Everything under `src/gen/` obeys the locked Tier 0 palette and the validator
enforces that per-pixel. Assets in this folder are UI chrome and are explicitly
**exempt** — the validator only inspects compositor output. Keep it that way:
if hand-authored art ever ends up inside the lot viewport it needs to be
brought onto the palette first, or the whole point of locking it is lost.
